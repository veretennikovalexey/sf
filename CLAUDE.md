# Проект: Python-аналог SkanerF

Консольное приложение на Python, которое слушает COM-порт и выводит в консоль данные, полученные со сканера штрихкодов (сканер настроен в режиме эмуляции COM-порта).

## Параметры порта (по умолчанию, как у SkanerF)

- Порт: COM6
- Скорость: 9600
- Биты данных: 8
- Чётность: нет (N)
- Стоповые биты: 1

## Решения по реализации

### 1. Суффикс окончания сканирования
**CR (`\r`)** — попробовать в первую очередь. Если работать не будет, скорректируем (попробуем `\n`, `\r\n` или чтение по таймауту).

### 2. Откуда брать имя COM-порта
Читать из существующего файла `SkanerF.ini` (тот же файл, что использует SkanerF.exe — НЕ удалять и НЕ создавать заново).

Из ini берём только параметр `ComPort` из секции `[Nastr]`:

```
[Nastr]
ComPort=COM6
```

Остальные параметры (Baud, Parity, StopBits, ByteSize) из ini **не читаем** — они там в формате SkanerF и нам не нужны. Скорость/биты/чётность/стоп-биты захардкодим в Python (9600, 8, N, 1).

### 3. Поведение, если COM-порт занят
**Вывести ошибку и завершить программу.** Сообщение типа: `Не удалось открыть COM6: порт занят. Закройте SkanerF.exe и попробуйте снова.`

### 4. Что делать с полученными данными
**Выводить в консоль + дописывать в файл** (append-режим, без перезаписи).

### 5. Файл для записи сканирований
- **Имя файла:** `SkanerF.txt` (то же имя, что использует SkanerF.exe).
- **Расположение:** текущая папка, где запущен Python-скрипт (НЕ читать путь из ini, всегда писать в текущую папку).
- **Режим:** если файла нет — создать; если есть — дописывать в конец (append, `'a'` mode).
- **Формат строки:** `2026-05-04 14:23:11 | 1234567890` (дата/время + код штрихкода).
- **Кодировка:** UTF-8 (существующий SkanerF.txt — ASCII, что является подмножеством UTF-8, поэтому совместимо).
- **Один файл и для SkanerF.exe, и для Python-версии.** Истории сканирований склеиваются (пользователь подтвердил).

### 6. Остановка программы
Через `Ctrl+C` (стандартный способ). Скрипт корректно ловит `KeyboardInterrupt`, закрывает порт и завершается.

### 7. Кодировка данных от сканера
**UTF-8** (читаем байты, декодируем в UTF-8). Если в штрихкоде только цифры/латиница — кодировка не важна, UTF-8 универсален.

## Файлы проекта

- `SkanerF.exe` — оригинальная программа (трогать нельзя).
- `SkanerF.ini` — конфиг (читаем `ComPort`, не модифицируем).
- `SkanerF.txt` — файл со сканированиями (общий для exe и Python-версии, append-режим).
- `scanner.py` — наша Python-программа.
- `README.md` — инструкция для пользователя на русском.
- `CLAUDE.md` — этот файл, контекст проекта.

## Зависимости
- Python 3.x
- `pyserial` (установка: `pip install pyserial`)
