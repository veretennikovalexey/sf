# SkanerF — Python-версия

Консольная программа на Python, которая слушает COM-порт и выводит данные, пришедшие со сканера штрихкодов. Это аналог программы `SkanerF.exe`, но написанный на Python.

Сканер должен быть настроен в режиме **эмуляции COM-порта** (а не в режиме клавиатуры). Тогда при сканировании штрихкода данные приходят в виртуальный COM-порт Windows, программа их читает и:

1. Выводит в консоль:
   ```
   Получены данные в COM6:
   1234567890
   ```
2. Дописывает строку с датой/временем в файл `SkanerF.txt`:
   ```
   2026-05-04 14:23:11 | 1234567890
   ```

---

## Что было сделано

1. Изучены параметры работы оригинальной `SkanerF.exe`:
   - имя порта берётся из `SkanerF.ini` (секция `[Nastr]`, ключ `ComPort`),
   - параметры передачи стандартные: `9600 / 8 бит / без чётности / 1 стоп-бит`.
2. Написан Python-скрипт `scanner.py`, который повторяет это поведение.
3. Скрипт пишет результаты в файл `SkanerF.txt` (тот же файл, что и оригинальная программа), в режиме дописывания.
4. В этот файл добавляется метка времени, чтобы было видно, когда именно был отсканирован штрихкод.

---

## Что в папке

- `SkanerF.exe` — оригинальная программа (не трогаем).
- `SkanerF.ini` — конфиг (общий с `SkanerF.exe`, не модифицируем).
- `SkanerF.txt` — файл, в который пишутся отсканированные коды (общий с `SkanerF.exe`).

- `README.md` — этот файл.
- `CLAUDE.md` — внутренние заметки по проекту (для Claude).

## Установка

### 1. Установить Python

Если Python ещё не установлен — скачать с [python.org](https://www.python.org/downloads/) (версия 3.8 или выше). При установке поставить галочку **"Add Python to PATH"**.

Проверить, что Python установлен:

```cmd
python --version
```

Должно вывести что-то вроде `Python 3.12.0`.

### 2. Установить библиотеку pyserial

Это единственная зависимость. Открыть командную строку (`cmd`) и выполнить:

```cmd
pip install pyserial
```

Если `pip` не находится — попробовать так:

```cmd
python -m pip install pyserial
```

## Настройка

Имя COM-порта программа берёт из файла `SkanerF.ini`. Открой его и убедись, что в секции `[Nastr]` указан правильный порт:

```
[Nastr]
ComPort=COM6
```

Если у тебя сканер на другом порту (например, COM3) — поменяй `COM6` на `COM3`.

> Узнать, какой COM-порт у сканера, можно в **Диспетчере устройств Windows** → раздел **Порты (COM и LPT)**.

Остальные параметры (`Baud`, `Parity`, `StopBits`, `ByteSize`) в ini-файле программа **не читает** — они используются только оригинальной `SkanerF.exe`. В Python-версии скорость, биты, чётность и стоп-биты захардкожены: `9600, 8, N, 1`.

## Использование

### Важно: закрыть SkanerF.exe

COM-порт может быть открыт только одной программой одновременно. Если у тебя одновременно запустится и `SkanerF.exe`, и `scanner.py`, **вторая программа выдаст ошибку** "порт занят".

Поэтому перед запуском Python-версии **закрой `SkanerF.exe`** (если он работает в трее — кликни правой кнопкой по иконке и выйди).

### Запуск

Открой командную строку **в папке со скриптом** и выполни:

```cmd
python scanner.py
```

Или двойным кликом по `scanner.py` (если установлен Python).

При успешном запуске увидишь:

```
Открываю порт COM6 (9600, 8N1)...
Порт COM6 открыт. Жду сканирования... (Ctrl+C для выхода)
```

### Сканирование

Просто наводи сканер на штрихкоды и нажимай курок. После каждого сканирования в консоли появится:

```
Получены данные в COM6:
4607034470012
```

И эта же строка с датой/временем допишется в `SkanerF.txt`.

### Остановка

Нажми **Ctrl+C** в окне консоли. Программа корректно закроет порт и завершится:

```
Остановка по Ctrl+C. Закрываю порт.
```

## Файл результатов SkanerF.txt

Все сканирования сохраняются в файле `SkanerF.txt` в той же папке, где запущен скрипт.

**Формат строки:**

```
2026-05-04 14:23:11 | 4607034470012
2026-05-04 14:23:18 | 5901234123457
2026-05-04 14:24:02 | 9788173712814
```

Слева — дата и время сканирования, справа — сам код штрихкода. Разделитель — ` | ` (пробел, вертикальная черта, пробел).

Файл открывается в **append-режиме**: новые сканирования всегда дописываются в конец, ничего не затирается. Если файла нет — он создастся при первом сканировании.

> **Важно:** этот же файл использует оригинальная `SkanerF.exe`. Если ты по очереди работаешь то через `SkanerF.exe`, то через `scanner.py` — все сканирования будут в одном файле (но с разным форматом строк, так как `SkanerF.exe` пишет только сам код, без даты/времени).

**Кодировка файла:** UTF-8.

## Возможные проблемы

### "Не удалось открыть COM6: порт занят."

Закрой `SkanerF.exe` (проверь системный трей рядом с часами), потом запусти `scanner.py` снова.

Если SkanerF не запущен, но ошибка повторяется — проверь, что в Диспетчере устройств порт `COM6` действительно есть и работает.

### "Не найдена библиотека 'pyserial'"

Установи её: `pip install pyserial`.

### Сканирую, а в консоли ничего не появляется

Возможные причины:

1. **Сканер настроен в режиме клавиатуры**, а не COM-порта. Тогда он "печатает" в активное окно, а не отправляет данные в порт. Нужно перенастроить сканер в режим виртуального COM (Virtual COM / USB-COM Emulation) — обычно это делается специальным служебным штрихкодом из инструкции к сканеру.
2. **Сканер шлёт другой суффикс окончания.** Программа ждёт `\r` (CR) после кода. Если сканер шлёт только `\n` (LF) или вообще без суффикса — данные накопятся, но не выведутся. Сообщи об этом — поправим программу.
3. **Не тот COM-порт.** Перепроверь имя порта в `SkanerF.ini` через Диспетчер устройств.

### Кракозябры вместо данных

Если штрихкод содержит нестандартные символы (например, кириллицу) — может быть проблема с кодировкой. По умолчанию программа ждёт UTF-8. Сообщи, что за коды ты сканируешь — скорректируем.

## Параметры по умолчанию (захардкожены в `scanner.py`)

| Параметр | Значение |
|---|---|
| Имя порта | из `SkanerF.ini` (`[Nastr]` → `ComPort`) |
| Скорость | 9600 |
| Биты данных | 8 |
| Чётность | нет (None) |
| Стоповые биты | 1 |
| Суффикс окончания сканирования | `\r` (CR) |
| Кодировка чтения | UTF-8 |
| Файл результатов | `SkanerF.txt` (текущая папка) |
| Режим записи | append (дописывание) |
| Кодировка файла | UTF-8 |

Если что-то из этого не подходит — отредактируй константы в начале `scanner.py`.
